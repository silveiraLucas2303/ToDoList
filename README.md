# ToDoList

Aplicativo de console em C# para organizar tarefas e acompanhar prazos.

## Funcionalidades

- Criar, listar e editar tarefas
- Iniciar e concluir tarefas
- Mostrar tarefas atrasadas e que vencem hoje
- Salvar as tarefas em JSON

## Como executar

É necessário ter o SDK do .NET 10 instalado. Na pasta do projeto,
execute `dotnet run`.

## Armazenamento

Atualmente, as tarefas são salvas em
`C:\code\ToDoList\dados\tarefas.json`.
